# Paper source

Compile the ten-page report from this directory with a recent Tectonic build:

```bash
tectonic report.tex
```

The source uses `apartpaper.sty`, the vector figures in `figures/`, and the
overview image in `../docs/figures/`. The submitted PDF is also available at
[`docs/report.pdf`](../docs/report.pdf). The style prefers STIX Two Text and
Avenir Next when installed and falls back to TeX Gyre or Latin Modern fonts.
